# Web Portofolio Yudi Awaludin

Website portofolio statis (HTML, CSS, JavaScript, Bootstrap). Buka `index.html` di browser atau pakai Live Server.

## Halaman
- `index.html` : beranda (sapaan, efek mengetik, counter, 3 karya pilihan)
- `about.html` : tentang, keahlian, pengalaman, pendidikan
- `project.html` : karya (filter, pencarian, modal detail)
- `contact.html` : formulir kontak dengan validasi

## Berkas
- `css/style.css` : gaya dan variabel warna (`:root` untuk mode terang, `[data-theme="dark"]` untuk mode gelap)
- `js/script.js` : seluruh interaktivitas. Data proyek, skill, pengalaman, dan pendidikan ada di bagian atas berkas
